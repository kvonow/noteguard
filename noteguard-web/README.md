# NoteGuard 클릭 시연

세로형 태블릿 화면을 위한 클릭 가능한 프로토타입입니다. 백엔드는 없습니다. 첫 책장에는 2026년 9월 모의고사가 보이지 않으며, 업로드 시연을 마치면 고정된 `math.pdf`를 올린 것으로 표시됩니다. 필기·채점·오답 분석·유사 문제는 준비된 예시 화면으로 연결됩니다.

## 실행

이 폴더에서 `npm start`를 실행하고 http://127.0.0.1:4173 을 엽니다.

## 시연 흐름

내 책장 → 모의고사 PDF 업로드 → 파일 선택 → 업로드 → 추가된 2026년 9월 모의고사 풀이 시작 → 문제 위를 클릭해 예시 필기 보기 → 채점 → 결과의 문항 화살표 또는 오답노트 → 오답 다시 풀기 / AI 피드백 → 유사 문제.

Figma 원본은 수정하지 않았습니다.
